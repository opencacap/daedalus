# 漢語のレジスター（短縮コアと抽象漢語）

生成AIの日本語には、自然な複合語・派生形から末尾を削って、より短い**裸の漢語コア**にする癖がある。完全形なら自然なのに、削ったコアだけが口語のレジスターから浮く。また、和語・カタカナで足りるところを、カバレッジの広い**抽象漢語**に持ち上げる癖もある。

**これは `references/phrases.md` の「空虚な語句」とは別系統の症状**。語の中身が空なのではなく、**形が削られすぎている／抽象度が上がりすぎている**。独立した観点として点検する。

## 判定ヒューリスティック

1. **完全形に戻すと自然になるか。** 戻して自然なら、コア形は削りすぎ。
2. **「これ、スタンドアップや立ち話で声に出して言うか？」** 書き言葉でしか出てこない漢語なら、レジスターを上げすぎ／削りすぎのサイン。

---

## まず：直してはいけないもの（残す）

**このファイルの目的は、漢語を一律に和語化することではない。** 定着した完全形・複合語・専門語彙はそのまま使う。削るのは「浮いた裸のコア」だけ。

| 残す形 | 理由 |
|--------|------|
| 整合性／論点整理 | どちらも定着した完全形・複合語。浮くのは「整合を取る」の裸用法だけ。 |
| 対応（順次対応します／対応窓口） | ビジネス日本語として完全に定着。複数の行為をまとめて指す場面では正用。個別作業を指すときだけ具体化を検討。 |
| 実施（研修を実施する／調査を実施した） | 監査・研修・調査・行政提出文書など、実施記録を残す正式文脈の標準語彙。 |
| 精査（数字を精査する） | 監査・与信審査・法務レビューでは工程名として定義された標準語彙。和語化すると情報が落ちる。 |
| 起票（チケットを起票する） | 稟議・経費精算・サービスデスク・ITSM で運用が実在する組織では正規の業務語。 |
| 訴求（訴求ポイント） | マーケティング・広告の標準語彙。和語化すると議論の粒度が落ちる。 |
| 拡張（機能を拡張する） | 行為・対象を指す名詞として自然。「拡張性」との使い分けはあるが、裸の「拡張」は削りかすではない。 |
| 競争優位／優位を保つ | 「競争優位」は経営学の定訳。裸の「優位」を一律に「優位性」へ直さない。 |
| 顕在化／形骸化／陳腐化 | 「化」の付いた完全形が正用（リスク管理・会計・経営の定着語）。 |
| 可用性／網羅的／網羅率 | IT・品質保証の定着した完全形。**むしろ削られたコアをここへ戻すのが目的**。 |

## パターンA：末尾を削った短縮コア

自然な完全形があるのに、末尾（性・度・化など）を落として裸のコアを吐く。**完全形に戻せば直る。**

| 浮いた形 | 例（AIが書きがち） | 戻す方向 | 正用として残す場面 |
|----------|--------------------|----------|--------------------|
| 妥当 | お見積もり金額の**妥当**を確認してご連絡します。 | 妥当性／その金額で合っているか | 「妥当な金額です」「妥当と判断しました」の形容動詞・述語用法。 |
| 一貫 | 各画面で用語の**一貫**が取れていません。 | 一貫性／表記をそろえる／ばらばらになっている | 「一貫して反対している」の副詞用法、「一貫生産」「首尾一貫」。 |
| 実効 | ルールの**実効**を担保する運用設計が必要です。 | 実効性／実際に効くか／守られるか | 「実効税率」「実効値」「実効支配」など専門複合語の前部要素。 |
| 網羅 | テストケースの**網羅**が不十分です。 | 網羅性／カバー範囲／漏れがないか | 「主要な論文を網羅している」のサ変動詞、「網羅的」「網羅率」。 |
| 可用 | 構成を二重化して、システムの**可用**を高めます。 | 可用性／落ちにくさ | SLA・SRE文書の「可用性」が定着した正用。口頭なら「落ちにくさ」。 |
| 優先 | このチケットは**優先**が高いので今週中に。 | 優先度／優先順位／先にやってほしい | 「Aを優先する」「優先席」「最優先」。高低で語るときだけ戻す。 |
| 難易 | 各タスクの**難易**を見積もって割り振ります。 | 難易度／どれくらい大変か | 「難易を問わず」は文語的慣用表現。書き言葉に限れば可。 |
| 透明 | 意思決定の**透明**を高めるため議事録を公開します。 | 透明性／プロセスを見えるようにする | 「透明な液体」「透明度」など物理的な意味。 |
| 属人 | 運用の**属人**を解消し、誰でも回せる体制にします。 | 属人化／属人性／その人しかできない状態 | 「属人化」「属人性」「属人的」はいずれも定着形でそのまま使う。 |
| 冗長 | DBの**冗長**を確保して単一障害点をなくします。 | 冗長化／冗長構成／二重化する | 「冗長な説明」の形容動詞用法（＝くどい）。 |
| 所要 | 現地までの**所要**は片道40分です。 | 所要時間／片道40分かかります | 「所要時間」「所要人数」の複合語。表組みの見出し列なら許容。 |

## パターンB：抽象漢語への持ち上げ

和語・カタカナ・具体的な動詞で足りるところを、カバレッジの広い抽象漢語に上げる。**社内チャット・口頭で硬化しやすい。**

| 浮いた形 | 例（AIが書きがち） | 戻す方向 | 正用として残す場面 |
|----------|--------------------|----------|--------------------|
| 認識 | リリースは来週という**認識**です。 | そう思っています／そう聞いています | 議事録の「認識相違」、契約前提の確認文。 |
| 齟齬 | 仕様の**齟齬**が生じておりました。 | 食い違い／ズレ／噛み合っていなかった | 契約書・障害報告書・監査資料の「齟齬なきよう」。 |
| 乖離 | 見積もりと実績に**乖離**が発生しています。 | 差が出ている／かなり違う | 決算説明資料・KPIレポートなど差分を定義して扱う文書。 |
| 展開 | 資料できたので、後ほど各位に**展開**します。 | 共有します／送ります | 「全社展開」「横展開」など施策が面的に広がる場合。 |
| 具備 | このツール、承認フロー機能を**具備**しています。 | 入っています／ついています／使えます | RFP回答・要件定義書の要件充足欄。 |
| 所感 | 昨日のMTGの**所感**を書いておきます。 | 感想／思ったこと／気づいたこと | 出張報告書・視察レポート・研修レポートの定型見出し。 |
| 逼迫 | 来週はリソースが**逼迫**しています。 | 手が空いていない／余裕がない | 在庫・電力・医療体制など社外公表の状況報告。 |
| 醸成 | チーム内で改善の文化を**醸成**していきたいです。 | 育てたい／根づかせたい／当たり前にしたい | 中期経営計画・人事方針など社外向けの理念文。 |
| 懸念事項 | 現時点での**懸念事項**を共有いたします。 | 気になっている点／引っかかっているのは | 提案書・リスク管理表・課題管理表の見出し語。 |
| 是正 | ドキュメントの記載を**是正**しておきます。 | 直しておきます／修正します | 労基対応・品質監査・是正処置報告書（CAPA）。 |

## 注意（過剰適用を避ける）

- **完全形・定着した複合語は残す。** 削るのは「浮いた裸のコア」だけで、漢語そのものを一律に和語化するのではない。
- **社外フォーマル文書・専門文書では漢語が正しいことが多い。** 上の「正用として残す場面」を必ず確認する。register を無視して和語に倒すのは、別種の slop（→ `references/registers.md`）。
- 「短ければ引き締まる」「漢語＝専門的っぽい」は**生成側のバイアス**。読み手の口語レジスターに合わせて戻すのが目的であって、短くすること自体が目的ではない。
- トークン化がコア形を後押ししている可能性はあるが、**因果は未確認**。現象（完全形は自然／削ったコアが浮く）だけを根拠に直す。
